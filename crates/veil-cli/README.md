# Veil CLI

`veil` 是 Veil 的命令行入口。它处理命令解析和用户交互，通过 `VeilService::execute` 调用容器操作；创建、解包和链接路径的业务校验由服务层完成。

## 文档边界

本文负责命令行为、参数、工作流和用户可见限制。密钥封装、磁盘格式、索引结构和恢复算法由 [Core 文档](../veil-core/README.md) 维护。遇到命令输出与内部格式需要分别理解时，应先在这里确认操作路径，再在 Core 文档确认存储语义。

## 安装与构建

开发构建使用 `cargo build --package veil-cli`，发布构建使用 `cargo build --release --package veil-cli`。构建产物为 `target/debug/veil` 或 `target/release/veil`。

也可以通过 `cargo install --path crates/veil-cli` 安装到 Cargo 的用户二进制目录。

## 空间与容器

本机应用数据库位于平台应用数据目录的 `Veil/app.db`；默认空间为 `Veil/spaces/<space_id>`。CLI 与桌面端共享同一目录策略。`VEIL_APP_DATA_DIR` 可指定测试或部署所需的绝对应用目录。容器目录以稳定 `veil_id` 命名，包含 SQLCipher `veil.db`、独立密文和加密暂存区。

空间、容器登记、设置和链接正文缓存统一由 service 访问。未解锁时使用登记缓存定位；实际操作会在解锁后校验容器身份。新设备可通过 `veil link <容器目录>` 输入密码重新登记。空间名称、容器名称和节点名称变化均不改变对应稳定 ID。

不读取旧 `~/.veil/config.jsonc`、移动盘旧配置、`.veil-info` 或旧打包格式。

## 详细命令

### 初始化

`veil init <veil-name>` 创建 Veil、`veil_dir`、配置记录和链接。密码可以交互输入，也可以通过位置参数、`--password` 或 `VEIL_PASSWORD` 提供。

初始化还支持以下选项：

| 选项 | 作用 |
| --- | --- |
| `--link <路径>` | 指定链接输出位置 |
| `--work <名称>` | 使用已注册的命名 Work，参数是名称而不是路径 |
| `--work-root <路径>` | 指定工作区根路径，自动登记工作区并关联当前 Veil |
| `--dedicated` | 让指定工作区只保存当前 Veil，目录仍为 `work_root/veil_id` |
| `--portable` | 标记便携创建流程；存储登记仍使用本机应用库，不能与 Work 选项同时使用 |

本机创建默认使用 `system_setting.default_space_id` 引用的空间。`--work` 可指定空间 ID 或唯一名称；`--work-root` 指定本机实际目录并登记为空间。空间位置会解析可确认的目录别名，默认管理目录为应用数据目录下的 `spaces/<space_id>`。

共享空间允许多个容器，专属空间只允许一个容器。容器目录为 `space_root/veil_id`；移动需由 service 协调磁盘与登记，不能手动只改归属。跨文件系统可使用打包与独立导入。

容器初始化已经提交后，如果链接或本机登记失败，错误会给出保留位置。更正输出路径后可重新生成链接；已提交容器不会作为链接失败的回滚对象。

### 添加文件

`veil add <veil> <源文件或目录>` 读取本地内容，加密后写入 `veil_dir`，并更新 `veil.db`。

单文件可以使用位置目标路径或 `-o` 修改 Veil 内名称。目录会递归导入，并保留相对目录结构；未指定目标时使用源目录名作为 Veil 内前缀。同名目标采用替换语义，不会累积重复条目。错误密码会在写入任何密文前失败。

### 列出和查看

`veil list <veil>` 输出文件名称、大小、加密时间和总大小。

`veil free <veil>` 按原始相对路径构造真实父子目录树，并使用 `├──`、`└──`、`│` 绘制标准树状结构。文件和目录按名称排序，目录名带 `/`。

`veil info <veil>` 输出 Veil 名称、稳定 ID、`veil_dir`、Work 类型、创建时间、文件数量、内容总大小、实际目录占用、MIME 类型分布和按虚拟路径排序的文件清单。

`veil exists <veil> <路径>` 判断 Veil 内文件或隐式目录是否存在。文件或目录存在时退出码为 `0`，不存在时输出 `不存在` 并返回退出码 `1`，适合直接用于脚本判断：

```bash
if veil exists photos.veil-link vacation/photo.jpg -p 'password'; then
  echo "file exists"
fi
```

### 导出文件

`veil ex <veil> <Veil 内路径> <输出路径>` 解密指定文件并写入本地路径。输出路径是必填项。

当前 CLI 按精确虚拟路径查找单个文件。虽然帮助文本保留了通配符描述，但当前命令层调用的是单文件导出接口。

### 删除和重命名

`veil rm <veil> <Veil 内路径>` 删除文件，或递归删除目录内的全部文件。路径会进行 Veil 内规范化，支持 `./tree` 这类写法；Veil 根目录和 `..` 路径逃逸会被拒绝。删除时会先提交更新后的元数据，再清理失去引用的密文。

`veil mv <veil> <原路径> <新路径>` 修改 `veil.db` 中的原始路径。文件可以重命名或移动到已有目录；目录移动只修改该目录节点的父关系或名称，查询时再组合后代路径。该操作不会移动或重命名磁盘上的随机加密文件名，也不会重新加密文件内容。

目标已经存在时拒绝覆盖；目录不能移动到自身或子目录。源路径和目标路径都会进行 Veil 内规范化，支持 `./tree` 这类写法。

### 修改密码

`veil passwd <veil>` 使用 SQLCipher 原生改密能力，独立文件的密钥与密文保持不变。

`veil passwd --full <veil>` 持久化一把 active 新文件密钥和一把 retiring 旧文件密钥，逐文件持写租约流式重写密文。文件通过 `key_id` 明确引用密钥；已迁移的文件直接跳过。所有文件迁移后切换数据库密码，验证成功后移除旧文件密钥。中断后使用必要密码继续，最多保留两把文件密钥，不改变文件 ID 或内容版本链。

位置参数形式为旧密码、新密码；选项形式使用 `--password` 和 `--new-password`。`--full` 也可以写作 `--reencrypt`。

### 交互式 shell

`veil shell <veil>` 验证密码后进入交互循环。当前支持：

| 会话命令 | 作用 |
| --- | --- |
| `ls` 或 `list` | 列出文件 |
| `info` | 显示 Veil 信息 |
| `add <文件>` | 添加文件 |
| `rm <文件>` | 删除文件 |
| `ex <文件> <输出>` | 导出文件 |
| `help` | 显示会话帮助 |
| `exit`、`quit` 或 `q` | 退出 |

Shell 不缓存派生密钥。每次文件操作仍由 `VeilManager` 读取并解密必要的元数据或文件，因此它主要提供操作便利，不应被描述为批量操作的性能缓存。

## 打包与解包

```bash
veil pack demo -o backup.veil
veil unpack backup.veil -n restored --link restored.veil-link
```

第 2 版打包文件包含加密数据库一致快照及所引用的密文，不重写文件内容。导出副本不保留源设备的运行锁；源容器的活跃锁保持不变。解包验证数据库身份、密文集合和全部分块认证后发布目录并登记。重复 ID、目标目录冲突和链接冲突均明确报错；取消登记与删除实际容器是不同操作。

## 配置与提示

`veil config` 和 `veil config show` 显示本机数据库位置、空间和登记数量。`veil config --hints full|brief|off` 持久化类型化用户偏好，`VEIL_HINTS` 只覆盖当前进程的提示级别。一次性提示存入本机记录，不追加操作日志，也不整体覆写配置。

## 链接管理

`veil link <名称、ID、链接或容器目录> -o output.veil-link` 生成便携入口。已有登记及身份缓存足够时无需输入密码；缓存不足时通过容器目录和密码解锁登记。链接缺失时，仅恢复本次访问目标的完整结构化缓存正文。

## 密码输入顺序

命令按以下顺序尝试获取密码：

1. 命令行参数或对应选项。
2. `VEIL_PASSWORD` 环境变量。
3. 当前终端交互输入。

新建容器或修改密码时，交互模式要求输入两次。参数和环境变量方式会跳过二次确认。

`veil passwd` 的旧密码使用 `VEIL_PASSWORD`，新密码使用 `VEIL_NEW_PASSWORD`。未设置新密码环境变量时进入交互输入，避免把旧密码静默复用为新密码。

命令行密码可能进入 shell 历史或进程参数列表。需要自动化的场景优先使用环境变量或受控的调用环境。

## 输出与本地化

CLI 默认输出中文，也可以通过 `VEIL_LANG` 选择语言。当前资源包含中文和英文。

Windows 控制台会根据输出代码页转换提示文字；Unix 平台按 UTF-8 输出。文件内容始终按二进制处理，不参与终端编码转换。

`veil help files` 显示各文件扩展名和容器文件的用途说明；`veil help <命令>` 可直接显示对应子命令帮助。`veil help all` 或 `veil help --all` 会输出顶层帮助以及全部子命令帮助。

### 错误码与退出码

所有错误统一输出为：

```text
❌ 错误 [1002]: 参数冲突: [密码] 不能与 --password <密码> 同时使用
```

错误码范围：

| 范围 | 含义 | 默认退出码 |
| --- | --- | --- |
| `1000-1999` | 命令行参数错误 | `2` |
| `2000-2999` | 密码错误 | `1` |
| `3000-3999` | 文件添加错误 | `1` |
| `4000-4999` | 配置错误 | `1` |
| `5000-5999` | `init` 初始化错误 | `1` |
| `6000-6999` | 链接错误 | `1` |
| `7000-7999` | 导出、打包和解包错误 | `1` |
| `8000-8999` | 帮助命令错误 | `1` |
| `9000-9999` | 底层核心错误和未分类异常 | `1` |

错误码和模板参数由统一的 `CommandError` 保存，最终由 CLI 边界按当前语言渲染。

## 并发与一致性

service 使用 SQLite 文件级租约，读读并发、读写互斥、写写互斥；流式工作不占用数据库写事务。提交复核身份、完整基础版本、活动文件密钥和锁凭证。写入新密文后再事务更新引用；失败后以数据库为准，不扫描磁盘重建清单。

普通改密不重写文件；完整改密以 active/retiring 两把密钥恢复中断进度。版本链只表示内容继承，不保留历史内容副本。

## 测试

CLI 测试位于 `crates/veil-cli/tests`，覆盖初始化、链接、配置、打包解包、密码修改、文件增删导出和 shell 会话。运行整个工程测试使用 `cargo test --workspace --all-targets`。

## 当前限制

- `ex` 当前只处理单文件。
- `shell` 不提供密钥或 Veil 对象的长期缓存。
- `passwd` 默认只重新保护元数据；`passwd --full` 会重新加密全部 `.enc` 文件。
- 链接按容器 ID 扫描已登记工作区；目标盘未挂载时报未找到，同 ID 的多个副本报告歧义。
- 忘记密码后没有恢复通道。
