# Veil Core

`veil-core` 提供统一 SQLCipher 连接、流式文件加密、版本链比较、执行身份和系统存活检查。业务表、文件租约及恢复流程由 `veil-service` 管理；客户端通过 service 调用业务能力。

## 磁盘格式

```text
应用数据目录/Veil/
├── app.db
└── spaces/<space_id>/<veil_id>/
    ├── veil.db
    ├── <lock_id>_<随机 UUID>.enc
    └── .staging/<lock_id>/
```

空间实际位置以 `space_info.local_path` 为准。`app.db` 是普通 SQLite，只保存本机登记、用户设置、系统设置和本机缓存，不保存容器密码或文件密钥。桌面端与同一系统用户的 CLI 使用相同目录；移动端由平台适配层提供应用私有目录。`VEIL_APP_DATA_DIR` 可显式注入绝对目录，供测试和部署使用。

`veil.db` 使用捆绑构建的 SQLCipher 4 和 OpenSSL。统一固定参数：4096 字节页面、256000 次 PBKDF2-HMAC-SHA512、HMAC-SHA512、零明文头。密码通过原生接口设置，实际读表验证解锁。构建启用内存临时存储，连接再次设置 `temp_store=MEMORY`、外键检查、完整持久化和 DELETE 日志模式；不得自行删改 SQLite 日志。

新格式不读取旧 JSONC 配置，不兼容 `.veil-info` 容器或第 1 版 `.veil` 包。旧数据需使用原版本导出内容后重新导入。

完整表结构、字段归属及产品边界见 [SQLite 存储设计](../../docs/sqlite-storage-design.md)。

初始化数据库成功后，链接或本机登记失败会保留已经提交的容器，并在错误中给出位置；失败请求不会删除其他请求创建的入口。

## 文件与版本

`file_ops` 继续使用 1 MiB 分块的 ChaCha20-Poly1305 文件格式。每个文件有独立的 12 字节基础 nonce，块序号参与 nonce 派生和 AAD。加密、解密和密钥轮换都采用流式处理，不将整个文件内容放入数据库或内存。

`metadata` 中的对象是查询结果和展示快照，不定义磁盘元数据格式。完整路径从 `file_info` 的父子关系生成，不作为权威字段，也不跨请求缓存目录树。

文件 ID 不随改名、移动或重新加密变化。内容变化追加版本 UUID；相同内容的覆盖不追加版本。版本链只记录继承关系，不保留历史内容副本。`version::compare_version_history` 按前缀判断关系，不按链长猜测新旧。

## 并发与一致性

业务锁保存在容器库的 `operation_locks` 中。同一文件允许多个读锁，写锁排斥同一文件的其他锁；不同文件可并行执行流式工作。长时间加密不持有数据库写事务。

service 统一定义 30 秒租约、5 秒续租、30 秒默认等待期限和 20 毫秒等待退避。申请支持超时、取消和整批申请；续租、释放、交接和提交都校验凭证。单调时间限制等待及本进程凭证有效性。执行身份和本机查询用于提前回收确认已结束的持有者，Unknown 按租约处理。

写入先生成并持久化新密文，再用短事务校验身份、父目录、基础版本、活动密钥和锁凭证，更新引用并释放锁。失败或崩溃后以数据库引用为准。清理器在删除前重新核对引用和运行锁，只处理协议可识别的候选对象，保留未知文件。

## 密码与备份

普通改密使用 SQLCipher 原生 rekey，文件密钥和文件密文保持不变。完整改密持久化一把 active 新密钥和一把 retiring 旧密钥，逐文件迁移；中断后通过密钥状态和实际引用恢复，最多两把密钥。数据库改密成功并验证后才移除旧密钥。

第 2 版 `.veil` 包包含加密数据库一致快照与所引用的密文。数据库快照段上限为 512 MiB，独立文件密文按 64 位长度流式处理。快照过程持有文件读租约，数据库通过在线备份接口复制；只清空导出副本的运行锁。解包验证身份、密文集合和全部分块认证后才发布并登记，不依赖源设备的应用数据库。

空间间移动通过 service 记录本机移动意图并执行目录原子重命名，可恢复移动后的登记。跨文件系统的原子移动由操作系统拒绝，此时使用打包和独立导入。

## 验证

```bash
cargo test --workspace
cargo test -p veil-service --features fault-injection --test storage_fault_tests
```

故障注入只在显式测试特性或单元测试中启用。覆盖写入、提交、密码切换、旧密钥移除、时钟跳变、并发持锁、清理和快照边界。规模测试包含宽目录 2000 个节点、深度 256 和 2257 个节点的子树，并检查实际查询计划与分页结果。
