# Veil 密码强度测试工具

`veil-brute-force` 用于测试自行创建的 Veil 单文件容器密码强度。工具会读取容器 Header 中的受保护私钥，再用候选密码尝试解封该私钥。

本工具只应用于授权测试和教育目的。不得用于访问、恢复或攻击他人的数据。

## 文档边界

本文只描述密码强度测试工具的输入范围、攻击模式、线程模型和授权边界。容器格式、密钥封装和恢复语义见 [Core 文档](../veil-core/README.md)；工具不能替代正式的密码审计或数据恢复流程。

## 支持的容器

当前工具面向 `veil-core::container` 单文件容器。它直接读取 `.veil` 文件 Header，不处理工作区目录、`.veil-link` 或 `.veil-meta`。

如果目标是工作区容器，当前工具不能直接使用；需要先确认项目中的单文件容器与打包文件格式，再选择对应测试对象。

## 构建与运行

发布构建使用 `cargo build --release -p veil-brute-force`，构建产物为 `target/release/veil-brute-force`。

也可以直接使用 `cargo run --release -p veil-brute-force -- <容器路径>` 启动。未在命令行提供路径时，程序会进入交互式路径输入。

## 工作流程

工具启动后先读取容器 Header，提取 `cip_pri_key`，随后根据攻击模式生成候选密码，并在线程池中并行调用私钥解密。

候选密码命中后会原子地设置停止标志。其他并行任务检查该标志并尽快结束，进度监控线程随后退出。

工具只需要 Header 中的密文私钥即可验证候选密码，不需要读取或解密整个容器内容。

## 攻击模式

主菜单提供以下模式：

| 选项 | 模式 | 说明 |
| --- | --- | --- |
| 1 | 字典攻击 | 从词表文件逐行读取密码 |
| 2 | 自定义字符集 | 选择字符组并设置长度范围 |
| 3 | 预设字符集 | 使用内置数字、字母或混合字符集 |
| 4 | 组词攻击 | 将多个单词按顺序组合为候选密码 |
| 5 | 线程配置 | 设置 Rayon 全局线程池大小 |
| 6 | 切换容器 | 重新读取另一个 `.veil` 文件 Header |
| 7 | 重试历史密码 | 重新尝试历史记录中的密码 |
| 0 | 退出 | 结束程序 |

### 字典攻击

词表文件按行读取，去掉每行首尾空白后忽略空行。历史记录中的密码会被过滤，剩余候选载入内存后进行并行搜索。

### 字符集攻击

自定义模式可以组合小写字母、大写字母、数字、符号和用户输入字符。选择完成后，字符集会排序去重，并按最小、最大密码长度逐批生成候选。

搜索空间按字符数的幂累加；超过 `u64` 表示范围时会饱和为最大值，并显示为超大搜索空间。

### 组词攻击

组词模式接收一组单词片段和组合数量范围。工具可以生成允许重复使用单词的排列，也可以生成不允许重复的排列。组合数量会在开始前预览。

## 线程与统计

工具使用 Rayon 并行执行候选密码测试。线程数默认使用检测到的 CPU 核心数，也可以通过菜单重新配置线程池。

尝试次数、运行状态和命中状态由原子变量共享，不需要互斥锁。进度监控线程每两秒读取一次统计值，并输出速度、最近两秒完成量和预计剩余时间。

并行任务的停止检查是协作式的。命中密码后，已经开始的其他任务可能在下次检查停止标志前完成少量额外尝试。

## 历史记录

历史目录名为 `.veil_history`，位于 `HOME` 或 Windows 的 `USERPROFILE` 下。历史文件名由容器绝对路径转换得到。

字典攻击和组词攻击在结束后会把本轮候选密码追加到历史文件。字符集攻击当前不写入历史。下一次攻击会读取并过滤已记录密码。

历史记录只用于避免重复尝试，不参与密码验证，也不包含容器私钥或明文内容。

## 密钥派生与性能

正常发布构建使用 `veil-core` 的标准 Argon2id 参数：内存约 256 MiB、迭代 3 次、并行度 4。

性能取决于 CPU、内存带宽、线程数、当前运行时 KDF 参数和容器格式。测试结果不能在未标明硬件和构建模式的情况下当作通用破解速度。

Debug 构建和 `VEIL_TEST_KDF=fast` 会降低 KDF 成本，只适合自动测试。使用这些参数测得的速度不能代表发布构建的安全强度。

## 使用建议

只在隔离环境中测试自行创建的容器。词表和结果文件应由测试者控制，避免引入来源不明的密码列表。

测试后应删除不再需要的弱密码测试容器。生产容器应使用足够长且唯一的密码，并使用密码管理器保存。

## 当前限制

- 当前实现只读取单文件容器 Header。
- 不能直接测试工作区容器的 `.veil-meta`。
- 字典和组词攻击需要把候选集合载入内存。
- 超大字符集可能在生成候选前耗尽内存或等待极久。
- 历史记录按容器路径生成，移动容器后会形成新的历史文件。
- 线程配置依赖 Rayon 全局线程池，线程池已经初始化后再次设置可能不会生效。

## 安全声明

该工具存在的目的是帮助用户理解密码强度和 Argon2id 的攻击成本。未经授权测试他人容器属于滥用行为。项目不提供绕过密码、恢复密钥或访问第三方数据的支持。
