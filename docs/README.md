## 🎯 核心设计要点

### 层级关系

```
工作区（Workspace）
  └── 容器目录（Container Directory）
      ├── .veil-meta（容器元数据）
      └── *.enc（加密文件）
```

### 三种工作区类型

1. **默认工作区**（共享）
   ```
   ~/.veil/workspaces/default/
     ├── veil-7f3a9c2d1b4e/
     ├── veil-91c2e8a4f63d/
     └── veil-2d9b1e7c4a80/
   ```

2. **自定义工作区**（共享）
   ```
   ~/Documents/veil-work/
     ├── veil-1f8c2d3e4a5b/
     └── veil-6c7d8e9f0a1b/
   ```

3. **专属工作区**（独占）
   ```
   ~/EncryptedVolume/veil/
     ├── .veil-meta
     └── *.enc
   ```

### 配置文件层级

| 文件 | 作用范围 | 数量 | 内容 |
|------|----------|------|------|
| **config.toml** | 全局 | 1 个 | 所有工作区、所有容器映射、全局设置 |
| **.veil-link** | 单个容器 | 每个容器 1 个 | 指向容器目录、加密参数模板 |
| **.veil-meta** | 单个容器 | 每个容器 1 个 | 文件列表、加密参数、统计信息 |

## 🚀 Veil 的独特价值

### 1. 创新的混合架构
- **工作区模式**：日常操作，独立文件加密，支持并发
- **容器模式**：分享传输，打包成单一文件

### 2. 极致轻量
- 2-5 MB 单文件
- 零依赖（vs Cryptomator 55MB + Java + 驱动）
- 拷贝即用

### 3. 开发者友好
- CLI 原生
- 脚本友好
- 服务器/容器环境完美支持

### 4. 文件组织能力
- 工作区分类管理
- .veil-link 快捷方式概念
- 灵活的容器组织

### 5. 无感体验
- 文件图标自动设置
- 渐进式揭示复杂度
- 提示系统可配置
