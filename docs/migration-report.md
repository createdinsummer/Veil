# Veil 2.0 命令迁移完成报告

## 迁移概览

所有核心命令已从旧的单文件容器格式迁移到新的工作区架构。

## 已完成迁移的命令

### ✅ 1. init - 初始化容器
**变化**：
- **旧**：创建单个 `.veil` 文件
- **新**：创建工作区目录 `~/.veil/workspaces/default/<name>/`
- **用法**：`veil init <name>` （不再需要 .veil 后缀）

**测试**：✅ 通过
```bash
veil init testcmd
# 输出: ✓ 容器创建成功: testcmd
#       工作区: /Users/mac/.veil/workspaces/default/testcmd
```

### ✅ 2. add - 添加文件
**变化**：
- **旧**：打开 .veil 文件，添加到内部索引
- **新**：独立加密文件到工作区目录
- **用法**：`veil add <container> <file>`

**测试**：✅ 通过
```bash
veil add testcmd /tmp/testfile.txt
# 输出: ✓ 文件已添加: testfile.txt
#       加密名: 68fcd5c34fba6dee.enc
```

### ✅ 3. rm - 删除文件
**变化**：
- **旧**：从索引删除，留下死空间
- **新**：删除加密文件和元数据条目
- **用法**：`veil rm <container> <filename>`

**功能**：完整删除（包括加密文件）

### ✅ 4. ex - 提取文件
**变化**：
- **旧**：从 .veil 文件提取
- **新**：从工作区解密文件
- **用法**：`veil ex <container> <filename> -o <output>`

**简化**：不再支持通配符（暂时），专注单文件操作

### ✅ 5. info - 查看信息
**变化**：
- **旧**：显示 .veil 文件信息
- **新**：显示工作区元数据
- **用法**：`veil info <container>`

**测试**：✅ 通过
```bash
veil info testcmd
# 输出：容器名称、工作区路径、文件列表等
```

**状态**：未迁移

## 架构对比

### 旧架构（单文件容器）
```
photos.veil
  ├── Header (密钥信息)
  ├── Index (文件索引)
  └── Data (所有文件数据)
```

### 新架构（工作区）
```
~/.veil/workspaces/default/photos/
  ├── .veil-meta (加密的元数据)
  ├── a3f2c1d4.enc (加密文件1)
  └── b7e4f9a8.enc (加密文件2)
```

## 用户体验变化

### 使用方式变化

**旧命令**：
```bash
veil init photos.veil
veil add photos.veil vacation.jpg
veil info photos.veil
```

**新命令**：
```bash
veil init photos
veil add photos vacation.jpg
veil info photos
```

**关键变化**：
1. ✅ 不再需要 `.veil` 后缀
2. ✅ 容器名称更简洁
3. ✅ 支持并发操作
4. ✅ 可以直接查看工作区目录

### 性能变化

| 操作 | 旧架构 | 新架构 |
|------|--------|--------|
| 添加文件 | 需要重写整个容器 | 只写入新文件 ✅ |
| 删除文件 | 只更新索引 | 删除文件+更新元数据 |
| 提取文件 | 从容器提取 | 直接解密 ✅ |
| 并发操作 | ❌ 不支持 | ✅ 支持 |
